===== PAGE 1 =====
海外大模型 API 聚合平台 MVP 一期
文档版本：V1.0
适用场景：纯大模型 API 中转服务、无复杂业务功能，仅验证海外客
户付费调用国内大模型的真实需求，先盈利后迭代
开发原则：极致精简、只做核心盈利链路、零多余开发、控制预算、
MVP 盈利后再投入二期功能
部署环境：新加坡服务器（适配海外访问、低延迟）
底层依托：基于开源 API 聚合框架二次开发，不自研底层网关，降本
提速
一、项目核心目标
1、搭建极简海外大模型 API 聚合平台，对外提供兼容 OpenAI 标准的
接口，海外客户可通过我方 API 安全调用国内通义、DeepSeek 等主
流大模型。
2、通过 Token 差价实现盈利，优先跑通付费闭环、验证市场需求，
不做任何冗余功能开发。
3、MVP 阶段实现正向现金流，用项目盈利资金投入二期功能迭代，
不额外追加自有成本。
4、小范围定向开放给海外 B 端客户，不公网大规模引流，降低合规
与运营风险。

===== PAGE 2 =====
二、一期需要功能
2.1 用户前台系统
仅保留基础账号能力，极简设计
1、邮箱注册、邮箱登录、邮箱验证码重置密码（唯一登录方式）
2、个人中心：展示账号美金虚拟余额、账号基础信息
3、API-Key 管理：新增、删除、启用/禁用、单 Key 限流（RPM/TPM）、
权限管控
4、充值中心：展示我方海外对公 T/T 美金收款账户信息、固定充值
档位展示
5、PI 形式发票 PDF 自助生成与下载（适配海外对公转账）
6、账单记录：充值记录、API 调用消耗记录，支持 CSV 导出对账
2.2 核心 API 网关服务
核心能力：海外客户转发调用国内大模型，差价盈利
1、对外完全兼容 OpenAI /v1/chat/completions 标准接口，支持流
式 SSE 输出、非流式输出，海外开发者可直接用 OpenAI SDK 对接
2、网关中转逻辑：海外客户请求→我方新加坡网关→转发至国内大
模型（通义、DeepSeek）→返回结果，全程隐藏上游密钥，保障安全
3、统一参数适配：自动适配各国内大模型接口差异，对外输出统一
标准格式

===== PAGE 3 =====
4、基础鉴权：客户 API-Key 校验，非法 Key 直接拦截，防止盗刷
5、基础限流：单用户、单 IP、单 Key 请求限流，防止恶意刷量打爆
上游账单
6、错误封装：统一报错返回，不暴露上游大模型原生报错信息
2.3 计费扣费系统
1、后台可自定义配置：各模型输入 Token、输出 Token 的美金单价
2、API 调用完成后，实时统计 Token 消耗，自动扣减用户账号虚拟
美金余额
3、余额不足时，直接拦截 API 请求，返回标准 402 欠费错误
4、每笔调用留存完整日志：时间、模型、Token 消耗、扣费金额、
用户 Key、TraceID，可追溯对账
5、平台余额为虚拟记账余额，仅可用于 API 调用消费，不支持提现，
规避合规风险
2.4 平台可调用大模型清单
为方便海外开发者清晰知晓可对接调用的模型资源、快速适配业务场
景，一期平台开放国内主流商用大模型，所有模型均已完成接口适配、
计费配置、格式统一，对外完全兼容 OpenAI 标准接口，开发者无需
额外适配即可直接调用。
平台一期支持全部大模型清单

2、每个模型独立配置输入/输出 Token 单价，后台可单独调价、管控
状态；
3、所有模型对外统一输出 OpenAI 标准格式，流式、非流式输出完全
兼容，客户无需区分底层模型差异。

===== PAGE 5 =====
2.5 充值模式
1、一期双支付模式：主推线上信用卡即时支付（主流便捷方式）+ 兜
底海外对公 T/T 美金电汇转账
2、客户自主下载 PI 发票，线下银行对公打款
3、线上信用卡支付（核心主推）：对接 Stripe 极简版支付通道，支
持 Visa/Mastercard 海外个人、企业信用卡即时充值，支付成功后系
统自动到账、实时更新用户余额，全程无人干预，适配海外用户线上
即时付费习惯，解决原线下转账繁琐、用户流失的问题；支持小额、
中额快速充值，贴合 API 按需消费的场景
4、线下对公转账（兜底补充）：客户可自主下载 PI 发票、线下对公
打款，转账完成后上传银行水单提交入账申请，运营后台一键审核入
账，适配海外 B 端大额对公采购、企业公账付款场景
5、支付风控极简配置：设置单笔充值限额、单日充值上限，拦截异
常支付、拒付风险，MVP 阶段规避信用卡高拒付、盗刷问题；支付手
续费透明，可后台配置手续费承担规则（用户承担/平台承担）
6、摒弃纯线下落后模式，贴合海外 SaaS/API 行业主流付费习惯，兼
顾线上便捷性、线下大额合规性，同时控制开发量与风控成本，不做
多余支付功能迭代

===== PAGE 6 =====
2.6 运营管理后台
1、用户管理：查看全量用户列表、冻结违规账号、手动调整用户余
额、查看用户全量充值与调用流水
2、模型渠道管理：添加上游大模型密钥、启停模型、配置模型计费
单价
3、充值订单智能管理：区分线上 Stripe 信用卡订单、线下对公转账
订单；信用卡支付订单系统自动标记已完成、无需人工审核，实时同
步支付状态与到账余额；线下转账订单支持人工核对水单、一键审核
入账、驳回异常订单
4、自动对账管理：系统自动同步 Stripe 支付流水、平台用户充值流
水、API 扣费流水，实现三方数据自动匹配，支持一键对账、异常订
单（支付成功未到账、扣款异常、金额不符）高亮预警，杜绝人工对
账延时、错账、漏账问题，适配线上高频即时支付场景
5、基础数据实时统计：实时展示总充值金额（线上/线下分开统计）、
总消耗金额、有效用户数、支付成功率、异常订单数，数据实时更新
无需人工汇总
后端客户 API 消费查看模块
（1）实时消费明细监控：后台可查看每一笔客户调用记录，精准区
分用户输入 Prompt Token、模型输出回复 Token，单独展示两类 Token
的数量、单价、单独扣费金额，杜绝笼统计费、对账模糊问题。

===== PAGE 7 =====
（2）单用户消费监控：支持按用户 ID/邮箱筛选，查看单个客户每
日/累计调用次数、总输入 Token、总输出 Token、总消费金额、剩余
余额，精准掌握客户消耗情况。
（3）单模型消费统计：按不同国内大模型维度，统计各模型总调用
量、总 Token 消耗、总营收，方便核算上游成本与单品毛利。
（4）异常消费监控预警：针对短时间高频调用、超大 Token 单条请
求、零输出异常扣费、余额透支请求进行日志标记，方便人工排查盗
刷、异常请求、计费 BUG。
（5）消费流水完整溯源：每笔消费绑定唯一 TraceID、用户 API-Key、
调用时间、模型型号、输入/输出原文脱敏日志，可 100%精准对账、
处理客户扣费异议。
